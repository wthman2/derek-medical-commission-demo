# Архитектура проекта

## Принцип работы

Проект — одностраничное React-приложение. Все данные находятся локально в `src/data/cases.ts`, поэтому интерфейс можно открыть и проверить без сервера, учётной записи пациента или внешней интеграции.

## Основные слои

| Папка | Назначение |
| --- | --- |
| `src/pages` | Маршрутные экраны: обзор, дела, история, анализ, сравнение, документы и досье. |
| `src/layouts` | Общая навигация приложения и навигация внутри дела. |
| `src/components` | Переиспользуемые элементы интерфейса и компоненты shadcn/ui. |
| `src/data` | Вымышленные дела, документы, события и сравнения. |
| `src/lib` | Вспомогательная логика для формирования сводок. |
| `src/types` | Общие типы предметной области. |

## Публикация

Workflow `.github/workflows/deploy-pages.yml` запускается после каждого push в `main`: устанавливает зависимости, собирает Vite-приложение и публикует папку `dist` в GitHub Pages.
